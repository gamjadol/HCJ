# K-TRIP NAVI (韓国旅行完全攻略ガイド)

일본인 방한 관광객(渡韓旅行者)을 위한 반응형 한국 여행 종합 가이드 웹사이트입니다.
10년 차 웹 퍼블리셔의 시맨틱 웹 표준, 접근성 및 사용자 인터랙션 최적화 원칙에 맞추어 설계 및 구현되었습니다.

---

## 1. 프로젝트 개요

- **사이트명**: K-TRIP NAVI (韓国旅行完全攻略ガイド)
- **주요 대상**: 한국 여행을 계획 중이거나 방문 중인 일본인 여행객
- **사용 언어**: 일본어 (UI, 설명), 한국어 (현지 표현 및 카타카나 발음 가이드)
- **목적**:
  - 한국 여행 전 필수 준비사항 점검 (인터랙티브 체크리스트 및 로컬스토리지 저장)
  - 결제 및 교통수단(WOWPASS vs 기후동행카드 vs T-money) 완벽 비교
  - 트렌디한 서울 핫플레이스(성수, 홍대, 명동, 한남) 및 부산 큐레이션
  - 식당, 카페, 쇼핑, 긴급 상황 시 원클릭 복사 가능한 실전 한국어 회화
  - 1330 관광통역안내, 대사관, 비상연락처 원터치 다이얼 연동

## 2. 기술 스택 및 라이브러리

- **Markup**: HTML5 (시맨틱 태그 구조화: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Styling**:
  - Tailwind CSS (유틸리티 클래스 기반의 일관된 디자인 시스템)
  - Custom CSS (`assets/css/style.css`): 글래스모피즘, 토스트 알림 애니메이션, 스크롤바 커스텀
- **Typography**: Pretendard, Noto Sans JP
- **Script**:
  - jQuery 3.7.1
  - Vanilla JavaScript ES6+ (`assets/js/main.js`)
- **Icons**: W3C 표준 인라인 SVG 벡터 아이콘 (무손실 해상도 및 이모지 미사용 원칙 준수)

## 4. 주요 기능 및 퍼블리싱 포인트

### 1) 입국 전 필수 준비 체크리스트 (Interactive Checklist)
- 사용자 체크 상태를 브라우저 `localStorage`에 자동 보관하여 새로고침 시에도 유지
- 완료 항목 수와 달성률(%)을 상단 프로그레스 바에 실시간 반영
- 전체 상태 초기화(리셋) 버튼 제공

### 2) 3대 교통 & 결제 카드 비교 가이드
- WOWPASS, 기후동행카드(관광권), T-money의 가격, 구매처, 장단점 및 추천 대상을 카드형 그리드로 일목요연하게 비교
- 한국의 현금 없는 매장(캐시리스) 문화 및 즉시 환급(Tax Refund) 팁 제공

### 3) 핫플레이스 동적 카테고리 필터링
- 성수, 홍대/연남, 명동/을지로, 한남동, 부산 지역별 필터링 기능
- jQuery 애니메이션을 적용한 부드러운 전환 효과

### 4) 실전 서바이벌 한국어 회화 & 클립보드 원클릭 복사
- 한국어 원문 + 카타카나 발음 + 일본어 번역 3단 구성
- [복사] 버튼 클릭 시 클립보드에 자동 복사되며 하단에 슬라이드 토스트 알림 표시
- 구형 브라우저 및 보안 컨텍스트 대응용 Fallback 구현

### 5) 24시간 1330 관광안내 & 긴급연락처 다이얼 연동
- 모바일 환경에서 탭 한 번으로 한국관광공사 1330(일본어 상담 무료), 112, 119 즉시 전화 연결

## 5. 퍼블리싱 가이드 및 학습 포인트 (튜터 노트)

1. **시맨틱 마크업**: 단순 `div` 남발을 지양하고 구획별 태그(`section`, `article`)와 제목 위계(`h1`~`h3`)를 엄격히 준수하여 검색엔진 최적화(SEO)와 스크린 리더 접근성을 확보했습니다.
2. **다국어 조판 배려**: 일본어와 한국어가 혼용되는 사이트 특성에 맞추어 `word-break: keep-all;` 속성을 적용, 단어가 어색하게 끊겨 줄바꿈되지 않도록 타이포그래피를 조율했습니다.
3. **가벼운 상태 관리**: 무거운 프레임워크 없이도 순수 자바스크립트와 jQuery의 간결한 DOM 조작 및 `localStorage` API를 활용하여 뛰어난 사용자 경험(UX)을 최소한의 파일 용량으로 달성했습니다.
