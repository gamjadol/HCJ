# 🚀 바이브 코딩(Vibe Coding) 포트폴리오

## 💬 소감

16개의 프로젝트를 하나씩 완성하면서, 모바일 청첩장 같은 감성적인 UI부터 QR 코드 생성, 문서·이미지·GIF·오디오 파일 처리, 추첨 애니메이션, PDF 병합, 문서 요약까지 — 처음엔 막막해 보였던 기능들을 직접 만들어봤어요.

프레임워크나 외부 서버 없이 순수 HTML·CSS·JavaScript만으로, 파일을 더블클릭해서 열어도 바로 동작하도록 만든다는 제약도 있었지만, 하나씩 원인을 찾아 해결하며 여기까지 완성했어요.
