# 0724 — 김민혜 포트폴리오

일어일문학과 대학교 4학년 김민혜의 초보 웹 개발자 포트폴리오입니다.

## 구성

- `index.html` — 포트폴리오 본문
- `profile.jpg` — 포트폴리오 대표 이미지

## 구현 내용

- 반응형 1페이지 포트폴리오
- About / Skills / Projects / Education / Contact 섹션
- 상단 내비게이션의 섹션 이동
- HTML 파일 내부에 CSS를 함께 작성한 단일 페이지 구조
- Google Fonts 사용
- 프로젝트 카드 및 기술 스택 표시
- 전화번호/이메일 연락 링크
- 모바일 화면 대응

## 프로젝트 소개

포트폴리오에는 학습 과정에서 제작한 다음 프로젝트를 소개합니다.

1. 교육자료 신청 및 만족도 설문
2. 스터디 시간 조율 페이지
3. 부산 여행 일정 페이지
4. 여수 MT 안내 페이지

## 사용 기술

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets
- Git / GitHub
- VS Code

## 실행 방법

`index.html`을 웹 브라우저에서 열면 확인할 수 있습니다.

## 참고

프로필 대표 이미지 파일은 포트폴리오 시각 요소로 사용하기 위해 포함되어 있습니다.
실제 취업 제출용으로 사용할 경우에는 본인이 사용 권한을 가진 프로필 이미지로 교체하는 것을 권장합니다.
