# 0901 — 교육자료 신청 및 만족도 설문

교육 후 수강생의 의견을 수집하고 Google Spreadsheet에 저장하는 Google Apps Script 웹앱입니다.

## 파일
- `Code.gs` — 웹앱 진입 및 설문 응답 저장
- `index.html` — 5단계 설문 화면
- `individual/` — 스터디 시간 조율 앱

## 실제 기능
- 5개의 설문 문항
- 객관식 선택
- 마지막 문항의 주관식 의견 작성
- 필수 문항 검증
- Google Spreadsheet 저장
- 제출 완료 메시지

## 설문 문항
1. 오늘 교육의 난이도는 어땠나요?
2. 가장 도움이 되었던 부분은 무엇인가요?
3. 교육의 진행 속도는 어땠나요?
4. 앞으로 어떤 교육자료가 가장 필요하다고 생각하나요?
5. 교수님께 남기고 싶은 말이 있나요?

## 실행
Google Apps Script 프로젝트에 `Code.gs`와 `index.html`을 추가한 뒤 웹앱으로 배포합니다.
`Code.gs`의 `SPREADSHEET_ID`는 실제 사용할 스프레드시트 ID로 설정해야 합니다.
