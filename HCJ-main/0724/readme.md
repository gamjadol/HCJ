# 0724 — 김민혜의 이력서

일어일문학과 대학교 4학년 김민혜의 이력서 페이지입니다.

## 구성

- `index.html` — 이력서 본문
- `css/style.css` — 스타일시트
- `images/` — 프로필 사진 및 연락처 아이콘(blog, email, facebook, mobile)
- `movie.mp4` — 자기소개 영상 (Projects 섹션에 삽입)

## 구현 내용

- My info / About / Contact / Skills / Projects 섹션으로 구성된 1페이지 이력서
- 상단 프로필 정보와 소개 글
- 연락처 아이콘(블로그, 이메일, 페이스북, 모바일)을 활용한 Contact 섹션
- Projects 섹션에 자기소개 영상 삽입
- 반응형 레이아웃

## 사용 기술

- HTML
- CSS
- JavaScript

## 실행 방법

`index.html`을 웹 브라우저에서 열면 확인할 수 있습니다.

## 참고

프로필 이미지와 자기소개 영상은 이력서 시각 요소로 사용하기 위해 포함되어 있습니다.
실제 제출용으로 사용할 경우에는 본인이 사용 권한을 가진 이미지/영상으로 교체하는 것을 권장합니다.
