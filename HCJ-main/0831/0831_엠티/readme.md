# 🔥 焼き Family 1박 2일 MT 안내 웹페이지

Google Apps Script 기반으로 제작된 모바일/PC 겸용 **1박 2일 MT 안내 단일 웹페이지**입니다.

## ✨ 주요 기능
- ⏳ **실시간 D-Day**: MT 날짜까지 남은 시간 실시간 계산
- 📅 **일정표 (타임테이블)**: 1일 차 / 2일 차 일정 탭 구분
- 🗺️ **오시는 길**: 이동 수단별 안내 & 네이버 지도 연결
- 🍖 **먹거리 & 레크리에이션**: 바베큐 라인업 및 게임 규칙 안내
- 📋 **준비물 체크리스트**: 터치해서 챙긴 물건 체크 (진행률 표시)
- 💰 **회비 정산표**: 총예산 및 1인당 회비 표시
- 👥 **역할 분담**: 팀원별 담당 역할 카드

## 🛠️ 기술 스택
- **HTML5 / CSS3 / JavaScript (Vanilla)**
- **Google Apps Script (GAS)**

## 📁 파일 구조
- `Code.gs`: MT 데이터(날짜, 장소, 일정, 예산 등) 설정 및 서버 렌더링
- `Index.html`: 화면 디자인 및 인터랙션 동작 소스

## 🚀 사용 방법
1. Google Apps Script에서 새 프로젝트 생성
2. `Code.gs`와 `Index.html` 작성
3. `웹 앱`으로 배포 후 URL 공유
