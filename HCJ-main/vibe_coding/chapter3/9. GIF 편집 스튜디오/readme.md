# 🎞️ GIF 편집 스튜디오 (예제 9)

업로드한 GIF를 리사이즈, 자르기, 포맷 변환까지 한 번에 처리할 수 있는 올인원 GIF 편집기예요.

## 주요 기능

- 파일 선택으로 GIF 업로드 후 편집
- **Resize(크기 조절)**: 확대해서 빈 공간 없이 채우기 / 단색 배경으로 채우기
- **Crop(자르기)**: 원하는 영역만 잘라내기
- **Downsizing(용량 축소)**: 해상도·프레임 간격 조정, LZW 압축 테이블 재정리로 용량 최적화
- **Format Convert(포맷 변환)**: MP4 동영상, JPG 이미지 등으로 변환
- Rotate & Flip, Reverse(역재생), Speed(속도 조절), Cut(구간 자르기) 등 편집 툴 제공
- 편집 결과 다운로드

## 기술 스택

- Vanilla HTML / CSS / JavaScript
- Tailwind CSS
- `<canvas>` 기반 프레임 처리

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열고 GIF 파일을 올리면 바로 사용할 수 있어요.
