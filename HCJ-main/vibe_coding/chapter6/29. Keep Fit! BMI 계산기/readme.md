# ⚖️ Keep Fit! BMI 계산기 (예제 29)

성별, 키, 몸무게를 입력하면 BMI와 목표 체중을 계산해주는 웹 앱이에요.

## 주요 기능

- 성별(남성/여성) 선택
- 신장(cm), 몸무게(kg) 입력
- "BMI 및 목표 체중 계산하기" 버튼으로 결과 확인
- 기준별 목표 체중 변화량(표준체중 90/100/110%) 안내

## 기술 스택

- Vanilla HTML / CSS / JavaScript

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열고 정보를 입력하면 바로 사용할 수 있어요.
