# 🎵 웹 오디오 에디터 (예제 32)

오디오 파일을 업로드해서 자르고, 볼륨을 조절하고, 포맷을 변환할 수 있는 웹 오디오 편집기예요.

## 주요 기능

- 클릭 또는 드래그로 오디오 파일(MP3, WAV 등) 업로드
- 재생 / 일시정지
- 볼륨 조절
- 변환할 포맷 선택
- 자르기 시작/종료 시간 지정
- "⚡ 편집 적용 및 파일 생성하기" 버튼으로 편집본 생성

## 기술 스택

- Vanilla HTML / CSS / JavaScript
- Web Audio API (`AudioContext`)

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열고 오디오 파일을 올리면 바로 사용할 수 있어요.
