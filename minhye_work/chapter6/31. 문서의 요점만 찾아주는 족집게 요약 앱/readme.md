# 🌐 글로벌 문서 요점 요약기 (Global Document Summarizer)

별도의 API 키나 백엔드 서버 설치 없이, 웹 브라우저에서 **PDF, DOCX, TXT** 문서의 주요 키워드와 핵심 문장을 자동으로 요약해 주는 100% 클라이언트 사이드 웹 애플리케이션입니다.

---

## ✨ 주요 기능 (Key Features)

- **🌐 다국어 지원 (한국어, 日本語, English 등)**
  - **한국어**: 조사 및 어미 정제 알고리즘 탑재
  - **일본어**: 한자(漢字) 및 가타카나(カタカナ) 명사 단위 정밀 토큰화
  - **영어**: 소문자화 및 불용어(Stopwords) 자동 제거
- **📁 다양한 문서 포맷 지원**
  - `.pdf`, `.docx`, `.txt` 파일 텍스트 직접 추출
- **🎚️ 요약 분량 조절 (1~5문장)**
  - 슬라이더를 통해 원하는 요약 문장 수(1문장~5문장) 자유 선택
- **🔑 핵심 키워드 Top 5 추출 및 형광펜 강조**
  - 문서 전체에서 빈도가 높고 중요한 핵심 키워드 5개 자동 선별
  - 요약된 문장 내 주요 키워드에 노란색 형광펜 패러다임 적용
- **🔒 안전하고 빠른 클라이언트 보안**
  - 모든 파일 분석과 처리 작업이 **사용자의 브라우저 내부**에서만 진행되어 데이터 유출 걱정 없음

## 🚀 사용 방법 (Getting Started)

별도의 라이브러리 설치나 `npm install` 과정이 필요 없습니다.

1. 본 저장소의 `index.html` 파일을 다운로드합니다.
2. `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)에서 실행합니다.
3. **[문서 파일 업로드]** 버튼을 눌러 요약할 문서(`.pdf`, `.docx`, `.txt`)를 선택합니다.
4. 슬라이더를 조절하여 원하는 **요약 분량(1~5문장)**을 선택합니다.
5. **[🚀 핵심 요점 요약하기]** 버튼을 클릭하여 결과를 확인합니다.
