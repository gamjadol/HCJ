# 🔮 나나도사 - 오늘의 운세 (Today's Fortune)

> **나나컴퍼니**에서 제공하는 웹 기반의 간단하고 직관적인 오늘의 운세 측정 서비스입니다.  
> 사용자의 기본 정보와 5가지 원소(불, 물, 나무, 땅, 바람) 선택에 따라 개인 맞춤형 운세를 제공합니다.

---

## 📌 주요 기능 (Features)

- 📝 **사용자 정보 입력**: 이름, 생년월일, 성별 입력 기능
- 🌿 **5대 원소 선택**: 불(🔥), 물(💧), 나무(🌲), 땅(⛰️), 바람(🌬️) 중 당일 마음이 이끄는 원소 선택
- 🔮 **맞춤형 랜덤 운세 출력**: 선택한 원소의 특성에 맞는 운세 지수(별점/점수) 및 상세 운세 설명 제공
- 👁️ **눈이 편안한 디자인**: 피로감을 줄여주는 은은하고 차분한 라이트 톤 UI 및 모바일 친화적 반응형 레이아웃

---

## 🛠️ 사용 기술 (Tech Stack)

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Design System**: Flexbox & CSS Grid, Pretendard Font
