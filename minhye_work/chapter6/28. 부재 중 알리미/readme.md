# ⏰ 부재 중 알리미 (Be Right Back Screen)

> **잠시 자리를 비웠을 때, 현재 상태와 복귀 예정 시간을 깔끔하고 세련되게 안내해 주는 모니터 화면용 웹 애플리케이션입니다.**

---

## ✨ 주요 기능

- **📌 핵심 정보 강조**: 일정을 화면에서 가장 큰 글씨로 시원하게 보여줍니다.
- **⏱️ 실시간 카운트다운**: 입력한 복귀 예정 시간까지 남은 시간을 초 단위로 자동 계산하여 표시합니다.
- **🎨 모던 글래스모피즘 UI**: 눈이 편안한 세미 다크 그러데이션 배경과 세련된 유리 질감(Glassmorphism) 카드 디자인을 제공합니다.
- **📱 반응형 레이아웃**: 대형 모니터, 태블릿, 모바일 등 어떤 화면 크기에서도 깔끔하게 맞춰집니다.
- **✏️ 간편한 수정**: 우측 상단의 '수정하기' 버튼을 눌러 언제든지 내용을 변경할 수 있습니다.
- **🚀 단일 파일 실행**: 별도의 설치 없이 `index.html` 파일 하나만 실행하면 즉시 동작합니다.

---

## 🛠️ 기술 스택

| 분류 | 기술 / 라이브러리 |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript (Vanilla JS) |
| **Typography** | Pretendard Web Font |
| **UI Design** | Glassmorphism, CSS Animation (`@keyframes`), Responsive Web (`clamp()`) |

---

## 🚀 사용 방법

1. `index.html` 파일을 다운로드합니다.
2. 웹 브라우저(Chrome, Edge, Safari 등)에서 `index.html` 파일을 실행합니다.
3. **일정 내용**, **돌아오는 시간**, **기타 안내 문구**를 입력한 후 `화면 표시하기` 버튼을 누릅니다.
4. 자리를 비우는 동안 모니터 화면에 켜둡니다.

---

## 📜 프롬프트 레시피 (Prompt Recipe)

이 프로젝트는 아래의 프롬프트 레시피를 기반으로 제작되었습니다.

> **[프롬프트 레시피]**
> - 잠시 자리를 비웠을 때, 화면에 정보를 표기해 주는 앱을 만들어 줘.
> - **사용자 동작**: 일정 입력, 언제 다시 돌아오는지 입력, 기타 문구 입력
> - 확인 버튼을 누르면 깔끔하고 아름다운 그러데이션 애니메이션 표시.
> - 일정, 돌아오는 시간과 카운트다운, 기타 안내 문구가 출력되도록 만들어 줘. 일정을 제일 큰 글자로.

---

## 📷 화면 구성 예시

1. **입력 화면 (Form View)**
   - 일정, 복귀 시간, 기타 안내글을 입력할 수 있는 다크 폼 레이아웃
2. **안내 화면 (Display View)**
   - **타이틀**: 제일 큰 가독성 높은 폰트로 일정 강조
   - **카운트다운**: `00분 00초 남음` 실시간 타이머
   - **기타 안내**: 메신저 연락 안내 등 서브 메시지 전달
