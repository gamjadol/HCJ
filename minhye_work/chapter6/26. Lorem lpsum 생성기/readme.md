# 📖 예제 26. Lorem Ipsum 생성기

> **Chapter 06. 바로 만들어 쓰는 1분 레시피 모음** (p.193)  
> **출처/제작**: 나나컴퍼니

---

## 📝 프롬프트 레시피 (Prompt Recipe)

> Lorem Ipsum 문자를 생성하는 웹 앱 하나 만들어 줘. 기본적으로 150자 정도 분량 글자를 띄워두고, 사용자가 슬라이드 바를 이동하면 그에 맞게 글자 분량을 수정하는 거야. 최소 10글자, 최대 5000글자.

---

## ✨ 주요 기능

- **브랜드 로고**: 상단 좌측에 `나나컴퍼니` 브랜드 표시
- **실시간 글자 수 조절**: 슬라이더 조작으로 10자 ~ 5,000자 실시간 반영
- **기본 세팅**: 실행 시 기본 150자 생성
- **클립보드 복사**: 버튼 클릭으로 생성된 텍스트 즉시 복사

---

## 🚀 사용 방법

1. `index.html` 파일을 브라우저(Chrome, Edge 등)로 실행합니다.
2. 슬라이더 바를 조절하여 원하는 글자 수를 설정합니다.
3. **[텍스트 복사하기]** 버튼을 눌러 복사합니다.

---

## 📂 파일 구성

- `index.html` - 웹 애플리케이션 메인 파일
- `README.md` - 프로젝트 안내 문서
