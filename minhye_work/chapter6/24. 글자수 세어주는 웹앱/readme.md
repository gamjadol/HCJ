# 📝 나나컴퍼니 글자 수 & 바이트 계산기

> 텍스트를 입력받아 실시간으로 글자 수와 바이트(Byte) 수를 정확하게 계산해 주는 웹 애플리케이션입니다.

---

## 📌 프로젝트 소개
**나나컴퍼니 글자 수 & 바이트 계산기**는 입력된 텍스트의 **공백 포함/제외 글자 수**와 **바이트 수**를 실시간으로 측정해 주는 웹 서비스입니다. 

자기소개서 작성, 문자 메시지(SMS/LMS) 글자 수 제한 확인, 데이터 입력 용량 체크 등에 활용할 수 있습니다.

---

## ✨ 주요 기능
- **실시간 계측**: 텍스트 입력과 동시에 글자 수 및 바이트 수가 즉시 업데이트됩니다.
- **다양한 기준의 글자 수 제공**:
  - 공백 포함 글자 수
  - 공백(띄어쓰기, 탭, 줄바꿈) 제외 글자 수
- **정확한 바이트(Byte) 계산**:
  - **한글 및 동아시아 문자**: `2 Byte` 적용
  - **영문 / 숫자 / 공백 / 기본 특수문자**: `1 Byte` 적용
- **브랜드 헤더**: 화면 왼쪽 상단에 `나나컴퍼니` 회사명 탑재
- **무설치 간편 실행**: 별도의 서버나 패키지 설치 없이 단일 HTML 파일로 동작
