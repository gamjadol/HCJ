# 📱 Smart QR - 웹 QR코드 생성기

**Smart QR**은 URL을 입력하여 쉽고 빠르게 QR코드를 생성하고 JPG 이미지 파일로 다운로드할 수 있는 심플한 웹 서비스입니다.

---

## 📌 주요 기능 (Key Features)

- 🖼️ **브랜드 헤더 구성**: 상단 좌측 로고 이미지(`logo.png`) 및 우측 사이트명(`Smart QR`) 배치
- 🎯 **인터랙티브 애니메이션**: URL 입력 후 확인 버튼을 누르면 입력창이 하단으로 이동하며 정중앙에 QR코드가 생성되는 연출
- 📥 **JPG 다운로드 기능**: 생성된 QR코드를 클릭하면 자동으로 `qrcode.jpg` 파일로 저장
- 🔗 **자동 URL 보정**: `http://` 또는 `https://`가 생략된 주소 입력 시 자동으로 URL 형식 보정
- 📱 **반응형 웹 디자인**: 모바일 및 데스크톱 환경 모두에서 깔끔하게 동작하는 모던 UI
