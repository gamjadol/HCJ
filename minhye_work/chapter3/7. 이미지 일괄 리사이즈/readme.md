# 🖼️ 이미지 일괄 리사이즈 (예제 7)

여러 장의 이미지를 원하는 비율로 한 번에 리사이즈해서 ZIP으로 받을 수 있는 웹 앱이에요.

## 주요 기능

- 컴퓨터에서 이미지 여러 장 선택 업로드
- 1:1 / 3:4 / 4:3 / 9:16 / 16:9 / 커스텀 비율 선택
- Crop(자르기) / Padding(여백 채우기) 방식 선택
- 처리된 이미지를 ZIP으로 일괄 다운로드

## 기술 스택

- Vanilla HTML / CSS / JavaScript
- `FileReader` API로 이미지 로드
- `<canvas>` 기반 리사이즈 처리

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열고 이미지를 올리면 바로 사용할 수 있어요.
