# 💍 감성 모바일 청첩장 (Mobile Wedding Invitation)

모바일 기기에 최적화된 우아하고 감성적인 **웹 모바일 청첩장** 프로젝트입니다.  
실시간 D-Day 카운트다운, 텍스트 파일(`문구.txt`) 자동 연동 인사말, 혼주 정보 및 갤러리 영역이 포함되어 있습니다.

---

## 📌 주요 기능 (Key Features)

- 📱 **모바일 최적화 레이아웃**: 스마트폰 가로 폭(Max 480px)에 맞춘 반응형 카드 형태 디자인
- ⏰ **실시간 D-Day 카운트다운**: 
  - 예식 일시까지 남은 **일, 시간, 분, 초**를 1초 단위로 실시간 계산 및 표시
  - 예식 당일 이후 자동 축하 메시지 전환 기능
- 🌸 **외부 인사말 텍스트 연동**:
  - `문구.txt` 파일이 존재할 경우 자동으로 해당 문구를 로드하여 출력
  - 파일이 없을 경우 감성적인 기본 인사말 자동 유지
- 👨‍👩‍👧‍👦 **혼주 및 신랑신부 소개**: 부모님 성함과 신랑·신부 관계 명시
- 🖼️ **웨딩 갤러리**: 그리드 형태의 웨딩 화보 사진 배치
- ✒️ **고풍스러운 폰트 적용**: Google Fonts의 `구운바탕`, `구운돋움`, `Noto Sans KR` 적용
