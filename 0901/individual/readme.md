# 스터디 시간 조율

스터디 구성원이 자신의 학번과 이름을 입력하고 가능한 시간대를 선택해 제출하는 Google Apps Script 웹앱입니다.

## 실제 기능
- 월~일요일, 5개 시간대의 선택형 시간표
- 학번 입력
- 이름 입력
- 동아리 활동 내용 입력
- 비고 입력
- 학번 중복 실시간 확인
- 같은 회차의 동일 학번 중복 제출 방지
- 회차(`CURRENT_ROUND`) 관리
- Google Spreadsheet 저장
- 제출 완료 메시지
- 동시 제출 방지를 위한 Script Lock 사용

## 스프레드시트 열
1. 타임스탬프
2. 회차
3. 학번
4. 이름
5. 가능한 시간대
6. 비고
7. 동아리 활동 내용

## 배포 전 확인
`code.gs`의 `SHEET_URL`, `SHEET_NAME`, `CURRENT_ROUND`를 실제 환경에 맞게 확인하세요.
